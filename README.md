# ぷよぽよシェイプ！

## ゲームの内容
「ぷよっ」と跳ねて、「ぽよん」と着地！

幾何学的な形の世界を、不思議な感触の「ぷよぽよ」と一緒に進もう。

画面をタップするだけの簡単操作なのに、クセになる弾力アクション！
静かに呼吸するように消えては現れる、幻想的な背景に癒やされながら、
あなたはどこまで高く（深く）進めるかな？

シンプルだけど奥が深い、新感覚のポヨン・アクションゲーム！

（プレイ中のスクリーンショットをドラッグ＆ドロップして追加する）

## 操作説明

使うのはマウスだけ！
左クリックで自機を掴める
掴んだ状態でマウスを動かすと引っ張ることができる！
左クリックを離すと引っ張りによって飛んでいく！
また掴んでいる状態で右クリックをすると形を変えられる
〇→△→◇の順番で変わるよ！
